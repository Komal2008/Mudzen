# 🛍️ Mudzen – Modern E-Commerce Platform

Mudzen is a full-stack e-commerce web application designed to deliver a seamless online shopping experience. It features a modern user interface, secure authentication, product management, shopping cart functionality, and an admin dashboard for efficient store management.

## 🚀 Features

### 👤 User Features

* User Registration & Login
* Secure Authentication
* Browse Products
* Search & Filter Products
* Product Details Page
* Add to Cart
* Update Cart Quantity
* Remove Items from Cart
* Responsive Design
* Order Placement

### 🛠️ Admin Features

* Admin Authentication
* Dashboard
* Add Products
* Update Products
* Delete Products
* Manage Orders
* Manage Users

## 🏗️ Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* React Router
* Axios

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* bcrypt

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/mudzen.git
cd mudzen
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd ../server
npm install
npm run dev
```

## 🔐 Environment Variables

Create a `.env` file inside the `server` folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
